# LIVANO Freight Services LLC – Company Website

## Project Overview
Developed a multi-page website for LIVANO Freight Services LLC, a logistics and freight services company.

The website provides information about the company's services, company background, contact details, quotation requests and shipment tracking.

## Website Pages
- **Home:** Company introduction and overview of freight services.
- **About:** Company information and background.
- **Services:** Sea freight, air freight and road freight services.
- **Contact:** Contact information and enquiry section.
- **Get a Quote:** Quotation request page.
- **Tracking:** Shipment tracking interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Font Awesome

## Key Features
- Multi-page website navigation
- Responsive website layout
- Freight service information
- Contact and quotation sections
- Shipment tracking interface
- Company branding and logo integration

## Project Purpose
This project provided practical experience in website development, frontend design, page structuring and implementing web interfaces for a business.
